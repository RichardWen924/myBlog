# Work 动效系统

## 1. 动效定位

Work 的动态语言是 **Precision Grid 中的受控能量**。动画用于建立结构、解释关系和确认交互，不承担持续装饰。

默认状态稳定；用户进入章节、聚焦节点或主动操作时才启动动态。Kinetic Type 只服务 Hero 与关键章节标题，普通内容使用更安静的揭示。

## 2. 时间 token

| Token | 数值 | 使用范围 |
| --- | --- | --- |
| `--work-motion-instant` | `120ms` | 图标、颜色和轻量状态确认 |
| `--work-motion-fast` | `180ms` | Hover 线条、箭头和标签反馈 |
| `--work-motion-base` | `320ms` | 面板切换、节点选择、普通交互 |
| `--work-motion-reveal` | `520ms` | 正文、项目行和时间线进入 |
| `--work-motion-chapter` | `720ms` | 章节标题和结构建立 |
| `--work-motion-hero-draw` | `1100ms` | Hero 描边绘制 |
| `--work-motion-hero-resolve` | `1400ms` | 描边到粒子或实心解析 |
| `--work-motion-transition` | `1280ms` | 每次跨越 Work 边界的点聚焦主题转场 |
| `--work-motion-ambient` | `2600ms` | 唯一允许的缓慢节点 pulse |

允许在实现时上下调整 8%，但同类组件必须共享 token，不能为每个实例创建独立时长。

## 3. 缓动 token

| Token | 值 | 使用范围 |
| --- | --- | --- |
| `--work-ease-enter` | `cubic-bezier(0.16, 1, 0.3, 1)` | 进入、展开和标题揭示 |
| `--work-ease-standard` | `cubic-bezier(0.22, 1, 0.36, 1)` | 普通状态变化 |
| `--work-ease-exit` | `cubic-bezier(0.4, 0, 1, 1)` | 快速退出 |
| `--work-ease-linear` | `linear` | 匀速信号沿线路移动；谨慎使用 |

禁止使用弹簧回弹作为全局语言。只有拖拽或具有真实物理含义的交互可以局部使用 spring，且必须限制 overshoot。

## 4. 位移、缩放与透明度

| 属性 | 桌面上限 | 移动上限 | 说明 |
| --- | --- | --- | --- |
| 内容进入 Y 位移 | `16px` | `8px` | 普通内容揭示 |
| 内容进入 X 位移 | `12px` | `6px` | 时间线或方向性内容 |
| Hover 位移 | `2px` | 不使用 | 项目行、标题或箭头 |
| 磁吸位移 | `4px` | 不使用 | 仅精确指针 |
| 指针视差近层 | `6px` | 不使用 | Hero 装饰层 |
| 指针视差远层 | `3px` | 不使用 | Hero 背景层 |
| Active 节点缩放 | `1.08` | `1.04` | 不能影响布局 |
| 初始透明度 | `0–0.35` | `0–0.5` | 关键信息不长期半透明 |

普通交互禁止使用超过 `1.08` 的缩放。章节进入不使用大幅横向飞入。

## 5. Stagger 规则

- 标题行：`60–90ms`。
- 项目行和经历条目：`70ms`，最多连续 6 项。
- 技术标签：`35–50ms`，最多连续 6 项。
- 能力节点建立：`50–80ms`，优先按关系层级而非 DOM 顺序。
- 超过 6 项时，分组启动或直接显示剩余内容，避免用户等待。
- 正文段落不做逐字动画。

## 6. 页面与章节时序

### 6.1 跨越 Work 边界

进入 Work 与离开 Work 的完整定义见 [`theme-transition.md`](./theme-transition.md)。核心时序：

1. `0–80ms`：锁定交互并建立 HUD。
2. `80–1160ms`：摄像机、点门户、百分比和 Work Hero 同步推进。
3. `320–860ms`：低对比结构速度线短暂建立并消失。
4. `1160–1280ms`：落位、清理临时层并恢复滚动与焦点。
5. Work Hero 的章节内部动效在主题转场完成后启动，不与穿梭转场竞争主焦点。

每次非 Work → Work 都完整播放 `0% → 100%`；每次 Work → 非 Work 都完整反向播放 `100% → 0%`。同一会话不跳过、不压缩。

### 6.2 章节进入

1. 章节结构线建立：`0–320ms`。
2. 标签和索引出现：延迟 `80ms`，持续 `320ms`。
3. 主标题揭示：延迟 `120ms`，持续 `720ms`。
4. 正文或证据组件进入：延迟 `240ms`，持续 `520ms`。
5. 交互节点启用：内容清晰后启用，不早于 `480ms`。

章节快速滚过时，不强制补播完整动画。进入视口后尚未完成的低价值动画可直接跳到最终状态。

## 7. 组件参数

### 7.1 `KineticHeading`

- 描边宽度：桌面 `1–1.5px`，移动 `1px`。
- 描边阶段：`720–1100ms`。
- 解析阶段：`1000–1400ms`。
- 标题整体位移：不超过 `8px`。
- 同一标题最多两阶段。
- 完成后停止，不循环散开。

### 7.2 `StrokeToParticle`

- 粒子尺寸：桌面 `1.5–2.2px`，移动降级或关闭。
- 粒子密度以不阻塞主线程为准；实现时按设备能力动态降级。
- 指针排斥范围：桌面 `90–130px`。
- 指针排斥位移：最大 `28–36px`，离开后在 `520–760ms` 内回归。
- Idle drift：最大 `0.35px`，且只能有一个活跃粒子场。
- 页面隐藏、离开视口或 reduced-motion 时暂停。

### 7.3 `MaskReveal`

- 时长：`520ms`。
- 位移：桌面 `12–16px`，移动 `6–8px`。
- 遮罩方向与阅读方向一致，默认由下至上。
- 同组 stagger：`70ms`，最多 6 项。

### 7.4 `LineDraw`

- 时长：`320–720ms`，依据线路长度。
- 短交互线使用 `transform: scaleX()`。
- 关系路径使用 SVG `pathLength`。
- 线路建立后保持静止，不持续闪烁。

### 7.5 `NodePulse`

- 周期：`2600ms`。
- 光环最大半径：节点尺寸的 `2.5–3倍`。
- 最大透明度：`0.18`。
- 同屏最多一个持续 pulse。
- 非当前节点不循环。

### 7.6 `DecryptedText`

- 字符更新间隔：`80–140ms`。
- 总时长不超过 `1600ms`。
- 只用于短标题或身份词。
- 完成后清理 timer，页面交换时清理 observer。

### 7.7 `MagneticResponse`

- 最大位移：`4px`。
- 输入映射使用组件边界内的归一化坐标。
- 返回时长：`320ms`。
- 仅 `(hover: hover) and (pointer: fine)` 启用。

### 7.8 `ProjectRow`

- Hover 标题颜色：`180ms`。
- 箭头位移：最大 `4px`，`180ms`。
- 整行 Y 位移：最大 `2px`；也可完全取消位移，仅使用结构线。
- Focus-visible 与 Hover 提供等价可见反馈。

### 7.9 `CapabilityMap`

- 初次线路建立：`720ms`。
- 节点 stagger：`60ms`。
- 选择证据面板切换：`320ms`。
- 非当前分支透明度最低 `0.22`，不能完全消失导致关系不可理解。
- 触控设备通过点击选择，不依赖 pointer move。

## 8. 滚动行为

- 大屏且视口高度充足时可使用章节吸附。
- 移动端、短视口和 reduced-motion 使用自然滚动或 `proximity`，不使用强制 `mandatory`。
- 键盘上下章节导航必须忽略输入框、按钮、链接和可编辑区域。
- 平滑滚动仅在未启用 reduced-motion 时使用。
- 滚动驱动动画使用可见进度，不逐帧读取多个布局属性。
- 返回页面顶部时，Hero 最终状态可以保持；不强制反向播放完整入场。

## 9. Reduced motion

当 `prefers-reduced-motion: reduce` 生效时：

- 禁用粒子、指针视差、磁吸、持续 pulse 和自动平滑滚动。
- 禁用强制章节吸附。
- `KineticHeading` 直接显示实心最终字形。
- `MaskReveal` 直接显示或仅使用不超过 `120ms` 的 opacity 变化。
- `LineDraw` 直接显示最终线路。
- 保留 active、hover、focus 的颜色和边框反馈。
- Loader 不播放完整主题过渡，也不延迟内容可用性。

Reduced motion 是完整体验，不是删除信息后的简化页面。

## 10. 性能预算

- 同时运行的持续动画对象：桌面最多 3 个，其中主要动态焦点最多 1 个；移动最多 1 个。
- 同屏粒子或 Canvas 场：最多 1 个。
- 普通动画优先只修改 `transform` 和 `opacity`。
- 不在 pointermove 中反复调用布局测量；边界在进入或 resize 时缓存。
- 指针更新通过 `requestAnimationFrame` 合并。
- 非首屏 React island 优先使用 `client:visible`。
- 离开视口、页面隐藏或 Astro 页面交换时清理 RAF、timer、observer 和事件监听。
- 动效不得造成横向滚动、布局位移或文字重排。
- 目标为主流设备稳定接近 60fps；低性能设备优先降级粒子密度和持续效果。

## 11. 验证清单

- 普通、快速和反向滚动时组件不会停留在半透明中间态。
- 多次进入 Work 不会重复绑定监听器或累计 timer。
- 键盘导航和点击不会被装饰层拦截。
- 页面隐藏后 Canvas、RAF 和持续动画停止。
- reduced-motion 下内容完整、顺序正确且无强制平滑滚动。
- coarse pointer 下没有依赖悬停或磁吸的必要信息。
- 320px 宽度与短视口下，动态标题不产生横向溢出。
